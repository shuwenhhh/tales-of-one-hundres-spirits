# 第三章开场对白初稿：雨中误入

中文剧情稿。人物沿用[第三章设定](CHARACTERS.md)：女主是小语，戴白狐面的男主是青砚。此场在雨中的迎亲山路触发，对白结束后进入与青砚的第一场交手。

## 演出与台词

雨越下越密。小语在岔路口看见一盏红灯，追过去，却只遇见站在路中央的青砚。他的衣服没有被雨淋透，袖口垂着一截红线。

**小语：** 请问，前面有能避雨的地方吗？

**青砚：** 有。你先别往前走。

**小语：** ……到底是哪边？

**青砚：** 这一带很不安全。你怎么到这里来的？

**小语：** 我想……我迷路了。

**青砚：** 迷路能迷到这里，也算有本事。

**小语：** 我只想找个屋檐。你指个方向，我马上走。

**青砚：** 这一带可不是你这样的小姑娘能随便走近的。对神明大人，要有敬畏之心。

**小语：** 我连祂的门在哪儿都没看见。

青砚低头。雨水把一根细红线冲到小语脚边，线头绕上她的鞋。

**青砚：** 你已经踩在门槛上了。

**小语：** 这是门槛？

**青砚：** 我也觉得太细了。可祂喜欢这样。

小语试着后退，红线却跟着绷紧。远处传来一声婚礼的锣，响得很轻。

**小语：** 我没有碰它。是雨把它冲过来的。

**青砚：** 我知道。所以你别动。我得先把你送出去。

青砚抬起缠线的手腕，红线从水面绷起，封住退路。小语撑开伞，挡下第一击。进入战斗。

## 表演要点

- 青砚的白狐面具始终戴在脸上；情绪靠停顿、低头看线和抬手表达。他并非因为小语顶嘴而动手，而是要在仪式把她卷进去之前把她推出界外。
- “我也觉得太细了”是一本正经的无厘头，不要用夸张表情或音效强调。
- 小语起初只想避雨；发现退路被封后才拿伞防身。第一击可表现为红线逼退或缠伞，不必让青砚直接伤她。
- 雨在对话和开战时持续落下。红灯、锣声和红线逐步提示“狐狸娶亲”，不在开场解释神明的身份。

## 事件顺序

`接近红灯 → 开场对白 → 红线缠鞋 → 青砚收线 → 小语挡击 → 战斗`。当前是线性初稿，没有玩家选项或剧情变量；战后对白另写。
