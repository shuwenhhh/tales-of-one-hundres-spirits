# Unarmed Wisteria Spirit dance and rest frames

Created with the built-in image generation tool from `single_hand/idle.png` and `single_hand/move_source.png` as identity references. The original tool output is `source.png`; `tools/normalize_wisteria_dance.gd` slices its 2 × 2 grid into `dance-00.png` through `dance-03.png`. Each runtime frame is 192 × 192 RGBA with a shared scale, fixed foot anchor near y=182, binary alpha and nearest-neighbor sampling. The combat sprites remain in `single_hand/`.

## Generation prompt

> Use case: identity-preserving production pixel sprite sheet for an existing Godot 2D game. Input image 1 is the exact Wisteria Spirit identity and game-scale pixel technique; input image 2 shows consistent full-body proportions and outfit across poses. Create exactly FOUR frames arranged in a 2x2 grid of equal square cells on genuinely transparent background. Each frame shows the SAME adult woman, in left-facing three-quarter profile, same recognizable face and head size, silver/lavender side-swept hair tied into a low bun with three tiny pale-purple blossoms, ivory wide sleeves, muted pink-lavender layered long skirt, sage green tied sash, small white shoes. Keep native crisp pixel-art clusters, muted purple outlines and restrained 3-4-shade ramps; no soft blur, antialiasing, gradients, glow, shadows, scenery, text, borders or extra objects. Absolutely NO vine, twig, branch, staff, weapon, green strand, or object in either hand. Both palms empty and relaxed. Four consecutive gentle dance poses, small planted steps, same character size, same head height/width and consistent foot baseline in every cell: frame 1 quiet starting stance, both arms naturally lowered; frame 2 small weight shift to her left with near sleeve opening slightly; frame 3 quarter turn and graceful slow outward hand gesture, hair curl and sleeves trailing; frame 4 return toward neutral, trailing skirt and hair settle. This is a subtle lonely dance under a tree, elegant and restrained, not jumping or spinning wildly. Whole figure fully visible with generous transparent margins in each equal cell. Preserve identity more strictly than pose novelty.

The game currently uses frames 0 and 3 for the same slow breathing and wind sway before the first conversation and after battle. The other generated poses remain source variants and are not used for the opening. The held vine and procedural whip are drawn only during combat.
